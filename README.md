# 국가기관 빙고

중학교 사회 「헌법과 국가 기관」 단원을 마무리하며, 배운 개념과 대한민국헌법의 조문을 연결하는 수업 자료입니다.

## 수업의 출발점

국가기관의 구성과 기능을 외우는 데서 나아가, 그 근거를 헌법에서 직접 찾아보게 합니다. 학생은 조문 옆에 관련 개념 번호를 적은 뒤, 헌법 조문 번호로 빙고판을 만들고 발표합니다.

교사가 처음 작성한 수업 개요는 [수업 개요 원문](docs/수업개요_원문.md)에 그대로 보존했습니다. 구체적인 진행 시간과 판정 규칙은 [수업 운영안](docs/수업운영안.md)에 정리했습니다.

## 바로 사용할 파일

| 자료 | 내용 |
| --- | --- |
| [빙고 진행 화면](index.html) | 실제 조문 표시, 관련 개념 공개, 학생 번호 추첨, 결번·결석 번호 제외, 표시한 조문 기록 |
| [학생용 학습지](outputs/국가기관_빙고_학생용.pdf) | 개념 목록, 빈 5×5 빙고판, 개념 번호 기입란이 있는 헌법 조문 목록 |
| [교사용 정답과 운영안](outputs/국가기관_빙고_교사용_정답과_운영안.pdf) | 개념별 헌법 조문 발췌문, 조문별 정답, 진행 방법, 판정 기준, 혼동하기 쉬운 내용 |
| [개념·조문 대응 자료](docs/개념과_헌법조문.md) | 개념 번호별 헌법 조문과 발췌문을 편집 가능한 글로 정리 |
| [정답표](docs/정답표.md) | 헌법 조문 순서로 개념 번호와 개념을 정리 |

학생용 PDF는 **A4 양면, 긴 쪽 넘김**으로 인쇄합니다. 4쪽이 학생당 두 장이 됩니다. 첫째 장 앞면은 개념 목록, 뒷면은 빙고판이며, 둘째 장 앞뒷면은 헌법 조문 목록입니다.

## 빙고 진행 화면 사용하기

1. `index.html`을 내려받아 Chrome 또는 Edge에서 엽니다. 설치나 인터넷 연결 없이 사용할 수 있습니다.
2. `추첨 설정`에서 마지막 학생 번호와 결번·결석 번호를 입력합니다. 제외할 번호는 `3, 8, 15`처럼 쉼표 또는 공백으로 나눕니다.
3. `학생 번호 뽑기`로 발표자를 정합니다. 기본 설정에서는 같은 번호를 중복해서 뽑지 않습니다.
4. 학생이 말한 조문을 선택하고 `화면에 띄우기`를 누릅니다. 필요한 때에만 `관련 개념 보기`로 개념을 공개합니다.
5. 연결이 맞으면 `맞아요 · 빙고판에 표시`로 기록하고, 틀리면 `오답 · 다음 차례`로 진행합니다. 마지막 표시는 취소할 수 있습니다.
6. 수업을 새로 시작할 때는 `새 수업`으로 발표·표시 기록을 지웁니다. 추첨 설정은 유지됩니다.

진행 화면은 빙고 완성 줄 수나 승리 조건을 지정하지 않습니다. 교사가 수업에 맞게 정합니다. 브라우저 저장 기능을 사용할 수 있으면 현재 진행 상황과 추첨 설정을 자동으로 저장합니다.

## 개념의 범위

총 46개 개념을 기관별로 구분했습니다.

| 기관 | 개념 번호 |
| --- | --- |
| 대통령과 행정부 | 1~19 |
| 국회 | 20~34 |
| 법원 | 35~39 |
| 헌법재판소 | 40~46 |

별 표시나 우선 학습 표시를 두지 않았습니다. 대통령의 법률안 공포·대법원장 및 대법관 임명·사면 권한은 대통령과 행정부 항목에 배치했습니다. 임명 과정의 국회 동의처럼 여러 기관이 관여하는 절차는 개념과 조문에서 함께 확인할 수 있습니다.

## 활동 순서

1. 개념 목록과 헌법 조문 목록을 나누어 줍니다.
2. 학생은 10분간 각 조문 옆에 관련 개념 번호를 적습니다.
3. 정한 범위에서 서로 다른 조문 25개를 골라 5×5 빙고판에 자유롭게 배치합니다. 칸에는 `제66조 제4항`처럼 조·항·호 번호를 씁니다.
4. 돌아가며 **조문 번호 + 조문의 핵심 내용 + 관련 개념 번호**를 발표합니다.
5. 연결이 맞으면 해당 조문이 있는 모든 학생이 표시합니다. 틀리면 아무도 표시하지 않고 다음 차례로 넘깁니다.
6. 가로·세로·대각선 중 3줄을 먼저 완성하면 빙고입니다.

10분은 최초 수업 구상의 연결 활동 시간입니다. 46개 개념 전체를 충분히 연결하려면 학급 상황에 따라 시간을 늘리거나 짝 활동으로 진행합니다. 자세한 운영 규칙과 묶음 조문의 처리 방법은 [수업 운영안](docs/수업운영안.md)을 확인하세요.

## 조문 표기 안내

조문은 수업에 필요한 항·호를 발췌했습니다. `……`는 중간 생략을 나타내며, 띄어쓰기는 읽기 편하게 정리했습니다. 원문과 구별해야 할 해설은 교사용 자료와 운영안에 명시했습니다.
