# 수업 운영안

## 목표와 준비

- 대상: 중학교 사회 「헌법과 국가 기관」 단원 마무리 수업
- 목표: 국가기관의 구성과 기능을 관련 헌법 조문에 연결하고, 권력 분립과 기관 간 견제를 설명한다.
- 준비물: 학생용 학습지 1인당 두 장(A4 양면 4쪽), 필기구, 교사용 정답표, 시간 확인 도구
- 학습 범위: 대통령과 행정부, 국회, 법원, 헌법재판소의 개념 1~46번.
- 권장 운영: 4~6명 모둠별로 돌아가며 발표한다. 전체 학급 운영도 가능하며 발표 순서를 미리 정한다.

## 진행 예시

| 단계 | 시간 | 활동 |
| --- | --- | --- |
| 안내 | 3분 | 학습 목표, 범위, 발표 순서와 판정 규칙 안내 |
| 연결 | 10분 | 조문 옆에 관련 개념 번호를 적기 |
| 빙고판 작성 | 4분 | 서로 다른 조문 25개를 자유롭게 배치 |
| 빙고 | 12~15분 | 조문과 개념의 연결을 발표하고 표시 |
| 마무리 | 3분 | 조문 하나와 그 조문이 정한 기관의 구성 또는 기능 설명 |

총 32~35분 예시이다. 46개 개념 전체를 연결하려면 학급 상황에 따라 연결 시간을 늘리거나 짝 활동으로 진행한다.

## 빙고판과 발표

빙고판에는 개념 이름 대신 조문 번호를 적는다. 예를 들어 `제66조 제4항`, `제111조 제1항 제5호`처럼 항·호까지 구분한다. 제104조 제1·2항과 제111조 제2·3항은 각각 한 묶음이며, 한 칸에 함께 적는다.

발표 예: “제66조 제4항, 행정권은 대통령을 수반으로 하는 정부에 속한다. 관련 개념은 4번입니다.”

교사는 조문 번호·핵심 내용·개념 번호의 연결을 확인한 뒤 표시하게 한다.

- 정답: 해당 조문이 있는 모든 학생이 표시한다.
- 오답: 아무도 표시하지 않고 다음 차례로 넘긴다. 오답으로 발표한 조문은 이후 다시 선택할 수 있다.
- 중복 발표: 이미 맞게 발표되어 표시한 조문은 다시 선택하지 않는다.
- 승리: 가로·세로·대각선 중 3줄을 먼저 완성한다. 동시에 완성한 학생은 공동 승리로 인정한다.

## 정답 판정 시 확인할 내용

1. 국회의 탄핵 소추(34번)와 헌법재판소의 탄핵 심판(44번)을 구분한다.
2. 법원의 위헌 법률 심판 제청(39번)과 헌법재판소의 위헌 법률 심판(42번)을 구분한다.
3. 제99조는 감사원의 결산 검사와 국회 보고를 명시한다. 국회의 결산 심사는 관련 개념을 연결한 것이며, 헌법에 “국회는 결산을 심사한다”라고 그대로 적힌 것은 아니다.
4. 제60조 제1항의 동의 대상은 헌법에 열거된 조약이다. 모든 조약에 국회 동의가 필요한 것은 아니다.
5. 제72조의 중요 정책 국민 투표와 제130조 제2항의 헌법 개정 국민 투표를 구분한다. 후자는 헌법 개정 절차상 필수이다.

## 개념 선정 원칙

국가기관의 구성과 기능 중 헌법 조문과 직접 연결되는 내용을 선정했다. 기관 이름만 제시하기보다 선출·임명·구성·권한을 구별했다.

상임 위원회의 법률안 심사, 각급 법원의 세부 사건 관할, 국회의원·장관 겸직의 세부 사항은 개별 법률의 규정이 중심이므로 별도 문항으로 넣지 않았다. 정부 형태와 권력 분립은 제41조·제67조, 제40조·제66조 제4항·제101조 제1항 등을 함께 보며 종합한다.

## 최종 학습지 구성

- 별 표시와 우선 학습 구분 없음
- 대통령과 행정부, 국회, 법원, 헌법재판소를 별도 항목으로 구분
- 기관별 개념 배치와 정답 번호 일치
